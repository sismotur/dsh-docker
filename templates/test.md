# Run the test suite and fix failures

Run the project's test suite. Report every failure with file path, line
number, and the assertion that failed. For each failure, analyze the root
cause and propose a minimal fix. Apply fixes only for failures with an
obvious root cause. For ambiguous failures, describe the suspected cause
and a proposed approach without changing code. Re-run the tests after each
fix to confirm it works. End with a summary: total tests, passed, failed,
fixed.
